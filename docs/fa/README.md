# مستندات و راهنماهای فارسی سامانه

این پوشه شامل مستندات اصلی و کاربردی سامانه‌ی حسابداری به زبان فارسی است:

| نام فایل | موضوع و محتوا |
| :--- | :--- |
| **`USER_GUIDE.md`** | راهنمای کامل سامانه‌ی حسابداری (سند روزنامه، کدینگ چهارسطحی، فروش، حقوق و مودیان) |
| **`LOCAL_SETUP.md`** | راهنمای اجرای گام‌به‌گام برنامه روی رایانه‌ی شخصی (ویندوز و مک) |
| **`DEBIAN_DEPLOYMENT.md`** | راهنمای جامع استقرار سروری روی Debian با Nginx و systemd |
| **`GETTING_STARTED.txt`** | متن شروع سریع و اعتبارنامه‌های پیش‌فرض |
| **`install-python-help.html`** | صفحه‌ی راهنمای تصویری برای نصب مفسر پایتون در ویندوز |
